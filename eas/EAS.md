# EAS 气质调查问卷

## 基本信息

| 属性 | 内容 |
|------|------|
| **全称** | EAS Temperament Survey (Emotionality, Activity, Sociability) |
| **作者** | Arnold H. Buss & Robert Plomin |
| **出版年** | 1984 |
| **出处** | Buss, A. H., & Plomin, R. (1984). *Temperament: Early developing personality traits*. Hillsdale, NJ: Erlbaum. |
| **条目数** | 20 题 |
| **适用年龄** | 儿童版：1-9 岁（父母评定）；成人版：成人自评 |
| **填答者** | 儿童版由父母/照料者填写；成人版由本人填写 |
| **评分方式** | 5 点 Likert 量表：1=完全不符合 (Not characteristic or typical)，2=比较不符合，3=一般，4=比较符合，5=非常符合 (Very characteristic or typical) |
| **版权状态** | 学术研究中广泛使用，原量表载于上述专著 |

## 理论背景

Buss 和 Plomin 的气质理论将气质定义为早期出现的、具有遗传基础的、在发展过程中相对稳定的人格特质。他们最初提出四个维度（EASI：情绪性、活动性、社交性、冲动性），后在 1984 年修订中去掉了冲动性维度（因其遗传基础不够稳定），增加了害羞维度，形成现行的四维度结构：

- **情绪性 (Emotionality)**：负性情绪唤起的强度和频率，尤其是痛苦、恐惧和愤怒
- **活动性 (Activity)**：偏好的活动水平和节奏
- **社交性 (Sociability)**：偏好与他人在一起而非独处的倾向
- **害羞 (Shyness)**：面对不熟悉的人时的行为抑制

## 量表结构

### 四个分量表

| 分量表 | 英文 | 题目数 | 定义 |
|--------|------|--------|------|
| 情绪性 | Emotionality | 5 | 指负性情绪反应的倾向和强度——即使是低强度的刺激也容易以焦虑、悲伤等消极情绪做出反应 |
| 活动性 | Activity | 5 | 指个体偏好的运动/活动水平，包括活动的速度和力度 |
| 社交性 | Sociability | 5 | 指偏好与他人在一起的倾向，寻求社会性刺激和互动 |
| 害羞 | Shyness | 5 | 指面对陌生人或新社交情境时的紧张、不自在和行为退缩 |

> **注**：部分研究将情绪性细分为三个子成分：痛苦 (Distress)、恐惧 (Fearfulness)、愤怒 (Anger)。

## 计分方法

### 分量表题目归属

| 分量表 | 题目编号 |
|--------|---------|
| 情绪性 (Emotionality) | 2, 5, 9, 13, 16 |
| 活动性 (Activity) | 4, 7, 11, 18(R) |
| 社交性 (Sociability) | 3, 8, 10, 14(R), 15, 20(R) |
| 害羞 (Shyness) | 1, 6, 12(R), 17(R), 19 |

> **注**：上表中活动性和社交性的题目数量可能因版本而异。部分版本中活动性为 5 题（包含额外题目），社交性为 5 题。具体题目归属请以获取的原始问卷计分手册为准。

### 计分步骤

1. 将标记 (R) 的题目进行反向计分（1↔5, 2↔4）
2. 将每个分量表的题目得分相加
3. 除以该分量表的题目数，得到平均分
4. 每个分量表得分范围：1.0-5.0
5. 得分越高，表示该气质维度越突出

## 心理测量学属性

| 指标 | 数值 |
|------|------|
| **内部一致性 (Cronbach's α)** | 情绪性 .70，活动性 .70，社交性 .77，害羞 .69（均值 .71） |
| **重测信度** | 中等到较好的时间稳定性 |
| **因子结构** | 四因子模型在多国样本中获得验证 |
| **跨文化验证** | 挪威、法国、荷兰、波兰、日本等多国版本 |
