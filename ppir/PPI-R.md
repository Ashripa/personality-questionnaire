# PPI-R (精神病态人格问卷-修订版)

## 基本信息

| 项目 | 内容 |
|------|------|
| 全称 | Psychopathic Personality Inventory-Revised |
| 作者 | Scott O. Lilienfeld & Michelle R. Widows |
| 出版商 | Psychological Assessment Resources (PAR), Inc. |
| 出版年份 | 2005 (PPI-R); 原版 PPI 于 1996 年出版 |
| 题目数量 | 154 题 |
| 适用对象 | 18-86 岁成人 |
| 施测时间 | 约 25-30 分钟 |
| 作答方式 | 4 点 Likert 量表 (1=不符合, 2=大部分不符合, 3=大部分符合, 4=符合) |
| 用途 | 精神病态人格特质评估；可用于社区和犯罪样本 |
| 特点 | 自评量表；不要求犯罪记录或访谈 |

## 量表结构

### 8 个内容量表 (Content Scales)

| 量表 | 英文名 | 题数 | 描述 |
|------|--------|------|------|
| 马基雅维利式自我中心 | Machiavellian Egocentricity (ME) | 20 | 为达目的不择手段，利用他人 |
| 社会影响力 | Social Influence (SOI) | 18 | 善于影响和操控他人的能力 |
| 冷酷无情 | Coldheartedness (C) | 16 | 缺乏同理心和内疚感 |
| 随意计划性 | Carefree Nonplanfulness (CN) | 19 | 缺乏前瞻性思维和计划 |
| 无畏 | Fearlessness (F) | 14 | 不惧危险，追求刺激 |
| 外归因 | Blame Externalization (BE) | 15 | 将问题归咎于他人或外部因素 |
| 叛逆不从众 | Rebellious Nonconformity (RN) | 16 | 蔑视传统和社会规范 |
| 压力免疫 | Stress Immunity (STI) | 13 | 在高压情境下保持冷静 |

### 2 个高阶因子 (Higher-Order Factors)

| 因子 | 英文名 | 包含量表 | 描述 |
|------|--------|----------|------|
| 无畏支配 | Fearless Dominance (FD) | SOI, F, STI | 社会影响力、无畏、压力免疫 |
| 自我中心冲动 | Self-Centered Impulsivity (SCI) | ME, RN, BE, CN | 自我中心、不从众、外归因、随意 |

> 注: Coldheartedness (C) 不负荷在任何一个高阶因子上，作为独立维度存在。

### 效度量表

| 量表 | 描述 |
|------|------|
| Deviant Responding (DR) | 异常回答检测 |
| Inconsistent Responding (IR) | 不一致回答检测 |
| Virtuous Responding (VR) | 美化回答检测 |

### 总分

| 分数 | 描述 |
|------|------|
| PPI-R Total Score | 8 个内容量表的综合分数 |

## 计分方式

- 各量表原始分汇总
- 转换为 T 分 (M=50, SD=10)
- 提供社区样本和犯罪样本双常模

## 心理测量学属性

- **内部一致性**: 总分 alpha = .93; SCI 因子 alpha = .92; FD 因子 alpha = .91
- **重测信度**: 内容量表 r = .82-.95; SCI 和 FD 因子分 r = .92 和 .95; 总分 r = .93
- **结构效度**: 二因子模型在多样本中获得一致支持
- **聚合效度**: 与 PCL-R (Hare 精神病态检核表) 有中等相关
- **区分效度**: FD 因子与焦虑呈负相关，SCI 因子与反社会行为呈正相关
- **跨文化效度**: 在瑞典、德国等非犯罪样本中得到验证

## 示例题目 (公开可见)

> PPI-R 题目为 PAR 版权保护。典型题目为关于个人态度、行为偏好和情绪体验的自我描述陈述，如关于冒险行为、人际互动方式、情绪反应模式等。

## 中文版本情况

- 目前未见正式出版的 PPI-R 中文版
- 中国精神病态研究中常用的替代工具包括: PCL-R 中文版、YPI 中文版、CAPP-SR 中文版等
- 部分研究者可能进行了 PPI-R 的研究性翻译，但未形成正式出版的中文版
