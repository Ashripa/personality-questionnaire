# TSCS-2 (田纳西自我概念量表 第二版)

## 基本信息

| 项目 | 内容 |
|------|------|
| 全称 | Tennessee Self-Concept Scale, Second Edition (TSCS:2) |
| 作者 | William H. Fitts & W. L. Warren |
| 出版商 | Western Psychological Services (WPS) |
| 出版年份 | 1996 (第二版); 原版 1965 年出版 |
| 题目数量 | 82 题 (成人版); 前 20 题可作为简版施测 |

## 量表结构

### 总分

| 分数 | 描述 |
|------|------|
| Total Self-Concept (TSC) | 总自我概念分数 |

### 双维度交叉结构

TSCS-2 采用独特的行-列 (Row × Column) 交叉结构:

#### 内部自我 (行量表, Internal/Row Scales, 3 个)

| 量表 | 英文名 | 描述 |
|------|--------|------|
| 认同 | Identity | "我是谁" — 对自我的基本描述 |
| 满意 | Self-Satisfaction | "我对自己的感受如何" — 自我接纳程度 |
| 行为 | Behavior | "我做了什么" — 对自身行为功能的看法 |

#### 外部自我 (列量表, External/Column Scales, 5 个)

| 量表 | 英文名 | 描述 |
|------|--------|------|
| 生理自我 | Physical Self | 对身体外貌、健康、体能的看法 |
| 道德-伦理自我 | Moral-Ethical Self | 对自身道德品质和宗教价值的看法 |
| 个人自我 | Personal Self | 对自身价值感和个人充足性的评价 |
| 家庭自我 | Family Self | 在家庭中的自我价值感和归属感 |
| 社会自我 | Social Self | 与他人交往中的自我价值感和能力 |

### 交叉结构矩阵

|  | 生理 | 道德-伦理 | 个人 | 家庭 | 社会 |
|---|---|---|---|---|---|
| **认同** | 生理认同 | 道德认同 | 个人认同 | 家庭认同 | 社会认同 |
| **满意** | 生理满意 | 道德满意 | 个人满意 | 家庭满意 | 社会满意 |
| **行为** | 生理行为 | 道德行为 | 个人行为 | 家庭行为 | 社会行为 |

> 3 行 x 5 列 = 15 个交叉单元

### 补充量表

| 量表 | 英文名 | 描述 |
|------|--------|------|
| 学业/工作自我 | Academic/Work Self-Concept | 学业或职业表现的自我评价 |
| 自我批评 | Self-Criticism | 承认常见但轻微缺点的意愿 (效度指标) |
| 冲突 | Conflict | 矛盾性自我描述的程度 |
| 防御性正向歪曲 | Defensive Positive | 夸大正面自我描述 |
| 一般失调 | General Maladjustment | 总体心理适应不良 |
| 精神障碍 | Psychotic Features | 严重心理障碍指标 |
| 人格障碍 | Personality Disorder | 人格障碍特征指标 |
| 神经症 | Neurosis | 神经症特征指标 |
| 人格整合 | Personality Integration | 人格整合程度 |

### 效度指标

| 指标 | 描述 |
|------|------|
| Inconsistent Responding | 不一致回答检测 |
| Self-Criticism (SC) | 自我批评量表兼作效度检查 |
| Distribution Score | 回答分布异常检测 |

## 计分方式

- 各量表原始分汇总
- 转换为 T 分 (M=50, SD=10) 和百分等级
- 简版 (前 20 题) 仅提供总自我概念分数
- 可手工计分或使用 WPS 评分软件

## 心理测量学属性

- **内部一致性**: 总自我概念分数 alpha 系数通常 > .90；各子量表 alpha 系数范围 .73-.93
- **重测信度**: 1-2 周间隔，总分 r = .82; 各子量表 r = .65-.82
- **结构效度**: 因子分析支持行-列双维度交叉结构
- **区分效度**: 可区分临床与非临床样本；不同临床群体间有差异性剖面
- **常模**: 基于美国样本，按年龄和性别分层

## 中文版本情况

- 台湾地区有 TSCS 中文版的翻译与修订使用
- 原版 TSCS 在中国大陆心理学研究中有应用，但 TSCS-2 的正式简体中文版出版信息有限
- 部分研究者进行了中文翻译和效度验证
- 如需正式中文版，建议联系 WPS 获取授权信息
