# MSCEIT (Mayer-Salovey-Caruso 情绪智力测验)

## 基本信息

| 项目 | 内容 |
|------|------|
| 全称 | Mayer-Salovey-Caruso Emotional Intelligence Test, Version 2.0 |
| 作者 | John D. Mayer, Peter Salovey, & David R. Caruso |
| 出版商 | Multi-Health Systems (MHS) Inc. |
| 出版年份 | 2002 (V2.0) |
| 题目数量 | 141 题 |
| 适用对象 | 17 岁及以上 |
| 施测时间 | 约 30-45 分钟 |
| 作答方式 | 5 点 Likert 量表 (多数任务) 或多选题 (理解领域) |

| 测验类型 | 能力测验 (最大表现测验)，非自评量表 |

## 量表结构

### 层级模型: 总分 → 领域分 → 分支分 → 任务分

```
总情绪智力分 (Total EI)
├── 经验性情绪智力 (Experiential EI / Area 1)
│   ├── 分支 1: 感知情绪 (Perceiving Emotions)
│   │   ├── 任务 A: 面孔 (Faces)
│   │   └── 任务 E: 图片 (Pictures)
│   └── 分支 2: 运用情绪促进思维 (Facilitating Thought)
│       ├── 任务 B: 促进 (Facilitation)
│       └── 任务 F: 感觉 (Sensations)
└── 策略性情绪智力 (Strategic EI / Area 2)
    ├── 分支 3: 理解情绪 (Understanding Emotions)
    │   ├── 任务 C: 变化 (Changes)
    │   └── 任务 G: 混合 (Blends)
    └── 分支 4: 管理情绪 (Managing Emotions)
        ├── 任务 D: 情绪管理 (Emotion Management)
        └── 任务 H: 情绪关系 (Emotional Relations)
```

### 四个分支 (Branches) 详述

| 分支 | 英文名 | 任务 | 测量内容 |
|------|--------|------|----------|
| 感知情绪 | Perceiving Emotions | Faces, Pictures | 从面部表情和图像中识别情绪 |
| 运用情绪 | Facilitating Thought | Facilitation, Sensations | 理解情绪如何与思维互动、情绪与感觉的关联 |
| 理解情绪 | Understanding Emotions | Changes, Blends | 理解情绪的转变过程和情绪的组合 |
| 管理情绪 | Managing Emotions | Emotion Management, Emotional Relations | 调控自身情绪和管理他人情绪的策略 |

### 分数层级 (7 个得分)

| 层级 | 分数 |
|------|------|
| 总分 | Total EI Score |
| 领域分 (2) | Experiential EI, Strategic EI |
| 分支分 (4) | Perceiving, Facilitating, Understanding, Managing |

(8 个任务分也可报告，但因题数少信度较低)

## 计分方式

两种计分方法 (高度收敛):

| 方法 | 描述 |
|------|------|
| 共识计分 (Consensus Scoring) | 基于大规模常模样本的多数回答，推荐使用 |
| 专家计分 (Expert Scoring) | 基于 21 位国际情绪研究专家的判断 |

- 原始分转换为标准分 (M=100, SD=15)
- 两种计分方式的相关系数极高 (r > .90)

## 心理测量学属性

- **内部一致性**: 总分 split-half 信度 r = .91-.93；领域分 r = .86-.90；分支分 r = .76-.91；任务级信度较低
- **重测信度**: 稳定
- **结构效度**: 因子分析支持四分支层级模型
- **区分效度**: 与言语 SAT 的相关系数 r = .23-.39，表明与分析智力有适度相关但不重叠
- **聚合效度**: 与自评式 EI 量表 (如 EQ-i) 的相关系数较低 (r = .21-.37)，证实能力型与自评型 EI 为不同构念

## 示例题目 (公开可见)

> MSCEIT 题目为 MHS 版权保护。典型题型包括:
> - 面孔任务: 呈现一张面部照片，要求评估该表情中各种情绪的含量
> - 图片任务: 呈现一幅风景或抽象图像，要求评估其所唤起的情绪
> - 混合任务: 要求识别哪种情绪是由两种基本情绪组合而成
