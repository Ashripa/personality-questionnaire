# PID-5-BF: Personality Inventory for DSM-5 -- Brief Form (25 Items)

## Citation

Krueger, R. F., Derringer, J., Markon, K. E., Watson, D., & Skodol, A. E. (2012).
Initial construction of a maladaptive personality trait model and inventory for DSM-5.
*Psychological Medicine, 42*(9), 1879-1890.

Krueger, R. F., Derringer, J., Markon, K. E., Watson, D., & Skodol, A. E. (2013).
The Personality Inventory for DSM-5 Brief Form (PID-5-BF).
American Psychiatric Association.

The PID-5-BF is freely available from the American Psychiatric Association:
https://www.psychiatry.org/psychiatrists/practice/dsm/educational-resources/assessment-measures

---

## Overview

The PID-5-BF is a 25-item self-report measure that assesses personality dysfunction across
five pathological personality trait domains from the DSM-5 Alternative Model for Personality
Disorders (AMPD). Each domain is measured by 5 items. The PID-5-BF items are drawn from
21 of the 25 trait facets in the full PID-5 (facets not represented: Restricted Affectivity,
Rigid Perfectionism, Submissiveness, Suspiciousness).

---

## Instructions to Respondent

> This is a list of things different people might say about themselves. We are interested
> in how you would describe yourself. There are no right or wrong answers. So you can
> describe yourself as honestly as possible, we will keep your responses confidential.
> Take your time and read each statement carefully, selecting the response that best
> describes you.

## Response Scale (4-point, scored 0-3)

| Code | Label                           |
|------|---------------------------------|
| 0    | Very False or Often False       |
| 1    | Sometimes or Somewhat False     |
| 2    | Sometimes or Somewhat True      |
| 3    | Very True or Often True         |

## Scoring

### Domain Scores

Sum the raw item scores (0-3) for the 5 items within each domain:

| Domain | Items | Raw Score Range |
|--------|-------|-----------------|
| Negative Affectivity | 8, 9, 10, 11, 15 | 0-15 |
| Detachment | 4, 13, 14, 16, 18 | 0-15 |
| Antagonism | 17, 19, 20, 22, 25 | 0-15 |
| Disinhibition | 1, 2, 3, 5, 6 | 0-15 |
| Psychoticism | 7, 12, 21, 23, 24 | 0-15 |

### Total Score

Sum all 25 items. Total raw score range: 0-75.
Average total score = Total / 25.

### Interpretation

Higher scores indicate greater personality dysfunction. APA does not publish specific cutoff scores for the PID-5-BF; clinical interpretation should be based on comparison with relevant normative data and clinical judgment.

## Full PID-5 (220-Item Version) Structure

The full Personality Inventory for DSM-5 (PID-5) contains 220 items measuring 25 trait
facets organized under 5 higher-order domains. Each facet contains 4-14 items.

### Domain and Facet Structure

| Domain | Facet | Items in Full PID-5 |
|--------|-------|---------------------|
| **Negative Affectivity** | Anxiousness | 9 items |
| | Emotional Lability | 7 items |
| | Hostility | 10 items |
| | Perseveration | 9 items |
| | Separation Insecurity | 7 items |
| | (Submissiveness)* | 4 items |
| | (Restricted Affectivity)* | 7 items |
| **Detachment** | Anhedonia | 8 items |
| | Depressivity | 14 items |
| | Intimacy Avoidance | 6 items |
| | (Restricted Affectivity)* | 7 items |
| | (Suspiciousness)* | 7 items |
| | Withdrawal | 10 items |
| **Antagonism** | Attention Seeking | 8 items |
| | Callousness | 14 items |
| | Deceitfulness | 10 items |
| | Grandiosity | 6 items |
| | Manipulativeness | 5 items |
| **Disinhibition** | Distractibility | 9 items |
| | Impulsivity | 6 items |
| | Irresponsibility | 7 items |
| | (Rigid Perfectionism)* | 10 items |
| | Risk Taking | 14 items |
| **Psychoticism** | Eccentricity | 13 items |
| | Perceptual Dysregulation | 12 items |
| | Unusual Beliefs & Experiences | 8 items |

*Note: Facets in parentheses with asterisk load on multiple domains or are cross-cutting.*

## Notes

- The PID-5-BF is in the public domain and freely available from the APA for clinical
  and research use.
- No items are reverse-scored; all items are keyed in the pathological direction.
- The PID-5-BF is suitable for adults aged 18 and older. A child version (ages 11-17)
  also exists.
- Administration time: approximately 5 minutes.
- Chinese validation studies found acceptable psychometric properties, though some
  studies suggest a six-factor model may better fit Chinese populations (splitting
  Negative Affectivity into two factors).
