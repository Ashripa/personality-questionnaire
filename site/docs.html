一、引言：人格测评与本库定位

人格测评（personality assessment）指借助标准化工具，对个体相对稳定的行为、情感、认知与动机倾向进行系统观测与量化的过程。它既是人格心理学积累实证知识的基本手段，也广泛服务于临床诊断辅助、组织人才评鉴、教育发展指导与个体自我探索。一份好的测评工具，本质上是把抽象的人格构念转译为可重复观测的操作定义，因而其价值高度依赖于信度（测量的一致性）与效度（测量确实反映了目标构念）的实证支持。

本库共整理 98 项人格及人格相关测评工具，覆盖 15 个理论流派或研究取向，从经典的特质问卷到投射技术，从临床病理量表到数字化前沿方法，尽量呈现该领域方法学的完整光谱。需要特别说明的是，收录范围有意区分了两类对象：一类是可直接作答的标准化量表（如自陈问卷、结构化评分表），另一类则是仅供参考的理论框架或方法论（如人格网络方法、经验采样法、整体特质理论）——后者并非某一份固定问卷，而是一整套分析范式，收录它们是为了呈现学科的方法学前沿，而非提供可施测的题本。

本文作为领域综述，力求在有限篇幅内交代各流派的核心思想、代表工具、方法学特点与固有局限，并对自陈与投射、西方与本土、版权与可获取性等横切议题给出中立评述。凡涉及具体信效度数值、样本规模等精确指标，除非属学科公认常识，本文一律以定性方式表述，以避免失真。

二、测量取向的历史脉络

人格测量的方法学演进，大体可勾勒为一条从"归类"到"维度"、再到"动态与数据驱动"的主线。最早占据主导的是类型学取向：无论是古典的体液气质说，还是荣格心理类型理论派生出的各类型划分，都倾向于把人归入若干离散范畴。类型论直观、易于传播，至今在大众文化中影响巨大，但其"非此即彼"的假设难以承载个体差异的连续性。

二十世纪中叶，特质论与因素分析逐渐成为学术主流。研究者借助词汇学假设与因素分析技术，从海量人格描述词中提炼出少数核心维度，Cattell 的多因素模型、Eysenck 的层级维度理论，以及后来汇聚为共识的"大五"结构，共同确立了"人格由可量化的连续特质构成"这一主导范式。与此并行，生物学取向试图为这些维度寻找神经生理与遗传基础，把气质差异追溯到反应性与调节系统的个体差异。

临床取向则沿另一条脉络发展：以能否区分临床群体与常人为条目筛选依据（经验效标法），或直接对接诊断系统的病理维度，形成了一批以效度量表与临床量表见长的工具。近数十年，随着诊断体系自身从类别走向维度，临床人格评估也经历了深刻转型。

进入当代，两股力量重塑着测量图景。其一是跨文化与本土化反思：研究者质疑西方模型的文化普遍性，主张从各文化自身的语言与哲学出发建构人格分类。其二是数字化新范式：智能手机、社交媒体与机器学习使"从行为足迹直接推断人格""一天多次测量人格状态"成为可能，人格由静态画像逐渐被理解为动态过程。至此，测评的核心问题从"你说你是什么样的人"，扩展到"你的行为数据显示你是什么样的人"。

三、十五大流派分类综述

以下按本库的分类体系逐一综述。每一小节交代该取向的核心思想、点名其中的代表工具，并简要评述方法学特点与局限。所提及的量表均为本库实际收录的真实工具。

3.1 特质论与因素分析

特质论是当代人格研究的主干范式，其核心主张是：人格由相对稳定、可量化的"特质"构成，可通过因素分析从大量描述词中提炼少数核心维度。以五因素模型为代表，NEO-PI-R / NEO-PI-3 被广泛视为大五测量的参照工具，跨文化验证充分，是元分析与教材的常用基准；BFI / BFI-2 以高效的短语式条目见长，适合大样本调查；IPIP 系列则是全球最大的公共领域人格题库，免费、可自由组合，成为开放科学的基石。HEXACO-PI-R 在大五之外增设"诚实—谦逊"维度，近年发展迅速。

更早的因素分析传统由 16PF 与 EPQ / EPQ-R 代表，前者是人才测评领域的老牌工具且有中国常模，后者强调人格维度的神经生理基础、在国内医学与教育界应用广泛。CPI 面向正常人的社交成熟度评估，EPPS 则以迫选格式测量心理需求以抑制社会称许性偏差。特质取向的优势在于结构清晰、可比性强、累积证据丰厚；其局限则在于以群体平均维度描述个体，可能忽略人格的情境性与内在动力过程。

3.2 临床与病理人格

临床取向以识别与刻画心理病理为目标。经验效标法的典范是 MMPI-2 及其现代重构版 MMPI-2-RF / MMPI-3，它们以完善的效度量表体系著称，能侦测作答者的掩饰、夸大与不一致，在精神科与司法评估中占据主导地位；MMPI-A / MMPI-A-RF 则为青少年群体专门调整。PAI 以量表间无条目重叠、解释清晰见长，MCMI-IV 专注人格障碍与临床综合征，并与诊断标准紧密关联。

近十余年，临床人格评估最重要的变化是从类别走向维度。PID-5 作为诊断体系"替代性人格障碍模型"的官方维度工具，将人格病理组织为若干病理域与其下的多个子面向，学术引用增长迅速；DAPP-BQ 从行为遗传学视角构建病理维度，SNAP-2 则搭建起正常人格与病理人格之间的连续谱桥梁。这一取向的方法学要点在于重视区分效度与临床效用；其挑战则包括量表普遍偏长、需要专业资质施测与解释，以及维度模型与传统类别诊断之间的衔接仍在持续磨合。

3.3 黑暗人格与反社会特质

该领域聚焦人格的"阴暗面"——自恋、马基雅维利主义与精神病态构成的"黑暗三联征"，以及后续纳入的施虐倾向，是近十年人格研究增长最快的前沿之一。亚临床层面的常用工具包括简版的 SD3 与极简的 Dirty Dozen；单一构念上，MACH-IV 是马基雅维利主义研究的奠基量表，NPI 是自大型自恋的经典工具，PNI 与 NARQ 则分别从病理性与"钦慕—竞争"两面弥补了 NPI 对脆弱型自恋覆盖的不足。Buss-Perry AQ 是攻击性测量的标准工具。

精神病态评估自成体系：PCL-R 是需专业认证、以半结构化访谈加档案审查完成的"金标准"，属非自陈工具；其自陈式对应物 SRP-4 与区分"适应性/非适应性"成分的 PPI-R 更适合非司法研究场景。方法学上，此类研究需高度警惕社会称许性与作答动机的干扰，且部分极简量表虽施测便利，信度有限，宜与其他工具交叉验证。

3.4 气质、生物学与神经敏感性

生物学取向主张人格差异可追溯到遗传、神经递质与生理机制，并倾向区分较为先天的"气质"与经社会化形成的"性格"。TCI-R 整合遗传学、神经生物学与心理学，在成瘾、抑郁的生物精神医学研究中应用广泛；BIS/BAS 量表与更新的 RST-PQ 操作化了强化敏感性理论，分别刻画行为抑制与趋近系统；SSS-V / BSSS 是感觉寻求研究的奠基工具，与生物学基础关联密切。

此外，HSP 量表测量"感觉加工敏感性"，近年与差异易感性理论结合而热度上升；DS14 则为心血管疾病风险研究设计，测量"D 型人格"。生物学取向的价值在于为特质提供机制解释，但也面临基因—脑—行为关联效应量偏小、结果重复性有待加强等共性挑战。

3.5 类型学取向

类型学将人格视为离散"类型"而非连续维度。MBTI 是全球知名度最高的人格工具，在企业培训与大众文化中影响力极大；RHETI（九型人格）在教练与灵性成长领域流行；DISC 则常见于组织发展与销售培训。必须中立指出的是，学界主流对这一取向的类型化假设持审慎乃至批评态度：这些工具普遍存在重测稳定性不足、因子结构不够稳健、类别切分缺乏实证依据等问题，因而不建议用于人事选拔或临床诊断。将其理解为促进自我觉察与团队沟通的"共同语言"，而非严肃测量，是较为稳妥的定位。

3.6 人际关系与依恋

该取向认为人格的核心表达在人际交往中展现。人际环形模型以"支配—顺从"与"友好—敌意"两轴构建二维空间，IAS 以形容词映射人际行为的空间位置，IIP-64 / IIP-32 则从"人际困扰"角度切入，二者互补且常用于治疗效果评估。依恋研究方面，ECR / ECR-R 是成人依恋自陈测量中使用最广的工具，将依恋从类型转为焦虑与回避两个连续维度；RQ 提供最简短的四类型筛查；AAI 则是评估依恋叙事连贯性的访谈"金标准"，但培训昂贵、施测与编码耗时。BORRTI 从客体关系理论切入，在严重人格障碍评估中有独特价值。

3.7 自我与社会认知

社会认知取向强调信念、期望与自我调节在人格中的核心作用——关注个体如何认知自我、解释因果、评价自身价值。控制源研究以 Rotter I-E 量表为奠基，Levenson IPC 进一步将其拓展为三维度；自我效能领域的 GSE 已被译为数十种语言，是健康与跨文化研究的常用变量。自尊测量以 RSES 为近乎"默认选择"的工具，简短且验证充分；TSCS-2 区分多领域自我概念，SCC 测量自我概念的清晰度。EIS（自我同一性地位）则操作化了同一性发展理论，在青少年与新兴成年期研究中影响深远。这一取向的方法学特点是构念聚焦、量表普遍简短易用，适合嵌入大型调查。

3.8 积极心理学与品格优势

积极心理学关注人格的积极面——品格美德、优势、韧性与心理繁荣，代表了从"修复损伤"到"培育优势"的转向。VIA-IS 是该运动的核心工具，建构了跨文化共通的美德与品格语言，全球已有大量在线作答者；CliftonStrengths 规模庞大但因商业封闭性，独立学术验证相对有限。韧性与坚毅方向有 CD-RISC、BRS 与 Grit-S；心理繁荣方向有幸福论取向的 PWB 与操作化 PERMA 理论的 PERMA-Profiler；组织情境下的 PsyCap / PCQ 关注可开发的心理资本。需中立标注的是，部分构念的独立性存在争议——例如 Grit 与尽责性高度重叠，其增量预测效度受到质疑。

3.9 情绪智力与情绪调节

情绪智力（EI）指感知、理解与管理情绪的能力或特质，测量上分为两大范式。能力型 EI以 MSCEIT 为代表，采用有"对错答案"的表现测验，被视为唯一被广泛认可的能力型 EI 测验，测的是与自陈量表不同的构念；特质/混合型 EI则以自陈问卷为主，EQ-i 2.0 是最早也最广泛使用的商业量表，TEIQue 明确将 EI 定位为人格层级底层的特质。此外，TAS-20 测量述情障碍（识别与描述情绪的困难），在心身医学与创伤研究中应用极广。两种范式的相关性偏低，选用时须先厘清究竟要测"能力"还是"自我知觉"。

3.10 价值观、道德与认知风格

人格也体现在个体优先看重什么、如何判断是非、偏好何种认知加工方式。价值观领域，SVS / PVQ-RR 是跨文化研究的全球标准，其环形结构揭示价值之间的兼容与冲突；RVS 以排序法区分终极价值与工具价值，是该领域的先驱。道德心理方面，MFQ 操作化了道德基础理论，揭示不同政治立场者的道德侧重差异。认知风格方面，NFC 测量享受深度思考的倾向，是说服与决策研究的标准调节变量；5DC / CEI-II 代表好奇心测量从单维到多维的演进；MPS（含 Hewitt-Flett 与 Frost 两个互补版本）是完美主义研究的标准工具；ASQ 则操作化了归因风格与习得性无助理论。

3.11 正念、自我决定与应对防御

该组工具涵盖正念觉察、基本心理需求与压力应对/防御机制。正念特质测量以多维度的 FFMQ 与单维度的 MAAS 为主，二者互补，是正念干预研究的常用前后测工具。BPNS 操作化自我决定理论的自主、能力与关联三项基本需求，是教育与工作动机研究的核心变量。应对策略方面，Brief-COPE 是最常用的简版工具，WCQ 则是基于认知评价理论的奠基性量表（部分分量表信度偏低是其已知局限）。DSQ-40 以自陈方式评估防御风格，把精神分析的防御概念量化——尽管"能否以自陈方式测量无意识防御"在理论上仍有争议。

3.12 儿童与青少年气质

气质被视为人格发展的生物学基础，在生命早期即可观测。Rothbart 体系构成了一条连贯的发展评估链：IBQ-R 面向婴儿期，CBQ 面向学龄前儿童，EATQ-R 延伸至青少年早期，三者以父母报告或自陈方式测量反应性与自我调节。EAS 基于气质遗传理论、简短易用，常见于双生子研究；NYLS 气质维度则是历史里程碑，其提出的"拟合优度"概念影响深远——强调问题不在气质本身好坏，而在气质与环境要求是否匹配。此类工具多依赖照护者报告，须留意报告者偏差与年龄段适配问题，切忌直接套用成人量表。

3.13 投射与非自陈方法

投射方法通过模糊或非结构化刺激，探索意识之外的动机、冲突与心理结构。Rorschach / R-PAS 是临床心理学的标志性投射工具，R-PAS 系统在标准化与国际规范方面有所提升；TAT 以对图片编故事揭示需要与客体关系；HTP / DAP 为绘画测验；RISB 是标准化程度最高的填句测验；Rep Grid 则源于个人构念理论，让受测者自行生成构念，形成高度个体化的评分矩阵。必须中立指出：投射技术的信效度长期存在争议，结果高度依赖评分系统与施测者训练，部分技术（如绘画测验）作为独立诊断依据的证据尤为薄弱，通常宜作为访谈的辅助而非单独定论。

3.14 跨文化本土量表

本土化取向直面一个根本问题：西方主流人格模型是否具有文化普遍性？其路径是从各文化自身的词汇、价值观与社会关系出发，发现文化特异性维度。CPAI-2 是最成功的非西方本土量表，其独有的"中国人传统性"因子难以被大五完全解释，为人格结构的文化特异性提供了实证；SAPI 从多种南非语言出发，纳入关系和谐等 Ubuntu 哲学维度；PUP 植根菲律宾本土心理学的 kapwa 概念。更具文化特异性的还有印度的三德人格量表、墨西哥民族心理量表，以及日本"甘え(Amae)"、韩国"情(Jeong)"等关系性构念——后者多为概念框架，尚缺乏统一标准化量表。这一取向挑战了"进口—翻译—验证"的单向范式，推动全球南方在人格研究中建立自主话语。

3.15 新范式与数字化前沿

前沿取向超越传统"潜在特质→自陈问卷"的框架。人格网络方法把人格视为因果连接的组分网络，而非潜在变量的反映指标，构成对特质本体论的挑战；整体特质理论（WTT）将特质分解为"行为的密度分布"与产生该分布的社会认知机制；CAPS 以"如果情境 X、则行为 Y"的 If-Then 签名重新定义一致性。测量技术上，DIAMONDS 系统化描述心理活性情境，填补了"情境"测量的空白；SAPA 项目借助项目反应理论实现自适应测试，以低成本获得高精度；CAQ（加州 Q 分类法）以强制分布排序刻画人格原型。数据驱动方向，数字足迹人格预测与开放词汇法分别从行为痕迹与自由文本推断人格，经验采样法（ESM/EMA）则捕捉人格状态的瞬时变动。这些方法多为分析范式而非固定量表，代表性强但也带来隐私与伦理方面的新争议。

四、横切议题

自陈 vs. 投射/非自陈。自陈问卷成本低、可标准化、便于常模化，是当代测量的主体，但易受社会称许性、作答动机与自我认知局限的影响——这也是 MMPI 系列以效度量表侦测作答态度、部分工具采用迫选格式的原因。投射与访谈类工具（如 Rorschach、TAT、AAI、PCL-R）意在绕开有意识的自我呈现，触及自陈难以企及的层面，但其信效度更依赖评分系统与施测者训练，标准化程度参差。二者并非优劣之分，而是各有适用边界；临床评估的黄金标准通常是多方法、多信息源的综合印证。

西方 vs. 本土化。大五等模型在众多文化中获得可观支持，但 CPAI-2 的"中国人传统性"、SAPI 的关系性维度等证据表明，某些文化特异的人格内容无法被现成的西方结构完全涵盖。稳妥的做法是：跨文化比较时优先选用经严谨本土验证的版本，必要时以本土量表补充西方工具，而非简单沿用未经适配的翻译版。

版权与可获取性。本库依获取难度将工具大致分级，理解这一维度对实际选用至关重要：

获取层级含义代表工具

信效度与文化适应。选用任何工具都应回到两个基本问题：它在目标人群中是否稳定可靠，是否确实测到了想测的构念。跨文化使用尤须核查是否存在经本土常模与测量等值检验支持的版本，避免"拿来即用"。

五、选用建议与优先级体系

没有"最好"的量表，只有"最适合特定目的"的量表。研究者应从构念定义出发选择效度证据最扎实、与既有文献可比的工具，并兼顾题量与样本可承受度；正常人格研究常以大五/六因素工具为通用语，病理研究则倚重维度化的临床工具。实践者（临床、组织、教育）除效度外，还须权衡资质要求、施测成本与结果沟通的可解释性，并遵守相应的专业伦理与版权规定。无论何种场景，都应避免仅凭单一工具、尤其是学术支持薄弱的类型化产品做出高风险决策（如选拔、诊断）。

为便于收集与取用，本库为每件工具标注了 P1–P5 优先级，其含义综合了学术认可度、可获取性与是否为自陈式：

优先级含义典型特征
P1 · 最优先金标准且开放/免费获取认可度最高、可自由使用，应最先收集
P2 · 高优先高认可度 + 论文公开或官网免费题项可从公开文献提取
P3 · 中等高认可度需学术渠道，或中等认可度且开放获取需一定门槛
P4 · 较低商业授权、专业施测或应用领域较窄成本或资质门槛较高
P5 · 暂缓理论框架/方法论、认可度低或极难获取非可直接施测的固定量表

需强调，优先级衡量的是"收集与取用的便利性及综合性价比"，而非工具的绝对学术价值。例如 NEO-PI-R、MMPI 系列、PCL-R 均属各自领域的金标准，却因商业或专业施测门槛而未列入最高收集优先级；反之，某些开放但认可度中等的量表因易于获取而优先级靠前。使用者应把优先级视为收集路线图，而非质量排名。

六、结语与免责声明

纵观全库，可以看到人格测评是一个方法多元、仍在快速演化的领域：特质模型提供了描述人格的通用坐标，临床与生物学取向深化了对病理与机制的理解，本土化与数字化前沿则不断挑战着既有范式的边界。领域内已形成若干共识——人格特质真实可测、具有生物学基础、成年期相对稳定但并非不可变；维度模型总体优于类型模型；单一工具不足以全面刻画一个人。与此同时，大五与六因素之争、"潜在特质"与"涌现网络"的本体论之辩、数字化预测的伦理边界等问题，仍是开放的前沿。
