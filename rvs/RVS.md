# Rokeach Value Survey (RVS)

## 基本信息

| 属性 | 内容 |
|------|------|
| **全称** | Rokeach Value Survey (RVS) |
| **作者** | Milton Rokeach |
| **出版年** | 1973 |
| **出处** | Rokeach, M. (1973). *The Nature of Human Values*. New York: Free Press. |
| **条目数** | 36 个价值观（18 个终极价值 + 18 个工具价值） |
| **适用对象** | 青少年及成人 |
| **施测方式** | 排序法（rank-order）：被试将 18 个终极价值和 18 个工具价值各自按照"对你个人生活的重要性"从 1（最重要）到 18（最不重要）排列 |
| **版权状态** | 公共领域 / 学术自由使用 |

---

## 概念框架

Rokeach 将价值观分为两大类：

- **终极价值 (Terminal Values)**：理想的终极存在状态（end-states of existence），代表个人一生中希望达到的目标。
- **工具价值 (Instrumental Values)**：理想的行为模式（modes of conduct），代表达到终极目标的手段。工具价值又可细分为：
  - **道德价值 (Moral Values)**：如诚实、宽恕——违反时会产生内疚感
  - **能力价值 (Competence Values)**：如有能力、有逻辑——与个人效能相关

## 施测与计分方法

### 施测指导语（英文原文）

> Below is a list of 18 values listed in alphabetical order. Your task is to arrange them in order of their importance to YOU, as guiding principles in YOUR life. Study the list carefully and pick out the one value which is the most important for you. Place a 1 next to it. Then pick out the value which is second most important for you. Place a 2 next to it. Then do the same for each of the remaining values. The value which is least important, relative to the others, should be ranked 18.

### 计分规则

1. 被试对 18 个终极价值进行 1-18 排序（1=最重要，18=最不重要）
2. 被试对 18 个工具价值进行 1-18 排序（同上）
3. 每个价值的得分即为其排名数字（越小越重要）
4. 可计算群体在各价值上的中位数排名进行组间比较
5. 不存在反向计分

### 中文版本

RVS 在中国心理学研究中有广泛使用，多项研究对其进行了中文翻译和应用。上表中提供的中文翻译为常见学术译法。

## 心理测量学属性

| 指标 | 说明 |
|------|------|
| **重测信度** | 终极价值中位数 r=.78-.80（3-5周间隔）；工具价值中位数 r=.70-.72 |
| **效度** | 大量跨文化研究验证了其结构效度；与政治态度、宗教信仰、职业选择等外部变量有显著相关 |
