# Ego Identity Status Interview (EIS)

## 基本信息

| 条目 | 内容 |
|------|------|
| 全称 | Ego Identity Status Interview (Identity Status Interview, ISI) |
| 缩写 | EIS / ISI |
| 类型 | 半结构化访谈 |
| 开发者 | James E. Marcia |
| 首次发表 | 1966 |
| 适用人群 | 青少年晚期至成人 (原始研究为大学生) |
| 施测时间 | 约 30-60 分钟 |
| 配套问卷 | EOM-EIS-2 (Extended Objective Measure of Ego Identity Status, 问卷版本) |

## 理论基础

基于 Erik Erikson 的心理社会发展理论中"同一性 vs. 角色混乱" (Identity vs. Role Confusion) 阶段,Marcia 将同一性形成操作化为两个核心维度:

- **探索 (Exploration / Crisis)**: 个体是否经历过对不同选择方案的主动探索
- **承诺 (Commitment)**: 个体是否已对特定价值观、职业或意识形态做出确定的选择

## 四种同一性状态

| 状态 | 探索 | 承诺 | 特征 |
|------|------|------|------|
| 同一性达成 (Achievement) | 有 | 有 | 经过探索后做出承诺 |
| 同一性延缓 (Moratorium) | 进行中 | 无 | 正在积极探索,尚未承诺 |
| 同一性早闭 (Foreclosure) | 无 | 有 | 未经探索就接受他人 (通常是父母) 的价值观 |
| 同一性弥散 (Diffusion) | 无 | 无 | 既无探索也无承诺,对同一性问题漠不关心 |

## 访谈领域

### 原始版本 (1966) -- 意识形态领域
1. **职业选择 (Occupation)** -- 职业方向的探索与承诺
2. **宗教信仰 (Religion)** -- 宗教观念的探索与承诺
3. **政治意识形态 (Politics)** -- 政治立场的探索与承诺

### 扩展版本 -- 增加人际领域
4. **友谊 (Friendship)**
5. **约会/亲密关系 (Dating)**
6. **性别角色 (Sex Roles)**

### 领域权重
研究表明: 意识形态领域对男性总体同一性状态预测力更强; 性别-人际领域对女性预测力更强。

## 访谈示例问题

**职业领域:**
- "Have you ever had any doubts about your career choice?"
- "What would you do if something changed and you couldn't pursue this career?"
- "When did you first become interested in [stated career]?"

**宗教领域:**
- "Have you ever had any doubts about your religious beliefs?"
- "How did you come to hold these beliefs?"

**政治领域:**
- "What do you think about current political issues?"
- "Have your views changed since you first began to consider them?"

## 施测与编码程序

1. **访谈实施**: 由受过培训的访谈者进行一对一半结构化访谈
2. **录音与转录**: 全程录音并转录
3. **编码**: 由受训编码者对每个领域分别判定同一性状态
4. **综合判定**: 根据各领域的状态组合确定总体同一性状态
5. **编码者间信度**: 通常报告 kappa > .70

## 客观问卷版本: EOM-EIS-2

| 条目 | 内容 |
|------|------|
| 全称 | Extended Objective Measure of Ego Identity Status -- Revised |
| 开发者 | Adams, Bennion, & Huh (1989) |
| 题目数 | 64 题 |
| 领域 | 意识形态 (职业、宗教、政治、哲学生活方式) + 人际 (友谊、约会、性别角色、休闲) |
| 计分 | 每种状态 16 题,6 点 Likert 量表 (强烈不同意 -- 强烈同意) |
| 使用 | 比访谈更经济,适合大样本研究 |

## 心理测量学属性

### 访谈版本 (ISI)
| 指标 | 数值 |
|------|------|
| 编码者间信度 (kappa) | .72-.96 (各领域) |
| 重测信度 | 中等至良好 (状态在发展过程中可变) |
| 结构效度 | 四种状态在自我概念、焦虑、权威主义等变量上呈现理论一致的差异 |
| 预测效度 | 同一性达成者在问题解决、道德推理等方面表现更优 |

### 问卷版本 (EOM-EIS-2)
| 指标 | 数值 |
|------|------|
| 内部一致性 (Cronbach's alpha) | .58-.80 (各状态分量表) |
| 重测信度 | .70-.90 |
| 收敛效度 | 与访谈分类中度一致 |

## 中文版本状况

- **EOM-EIS-2 中文版**: 已有中文翻译版本在中国大陆和台湾地区使用 (自我同一性状态量表),发表于《国际精神病学杂志》等期刊
- **文化适应问题**: 中国被试反映宗教和约会领域的部分题项与中国文化情境关联度较低
- **本土化修订**: 部分中国研究者对访谈领域进行了文化调整,如将宗教替换为人生哲学,增加学业领域
- **访谈版本**: 中文访谈版本使用较少,多数中国研究采用 EOM-EIS-2 问卷版本

## 版权与获取

- **访谈协议**: 原始访谈框架发表于 Marcia (1966) 及后续著作中,可在学术文献中获取
- **EOM-EIS-2**: 问卷可通过联系原作者 (Gerald R. Adams, University of Guelph) 获取,通常可用于学术研究
- **编码手册**: 详细编码指南见 Marcia 等 (1993) 的著作 *Ego Identity: A Handbook for Psychosocial Research*
- **培训**: 无需像 AAI 那样的正式认证,但建议通过研读手册和与有经验的研究者合作来确保编码质量
