# Repertory Grid Technique (Rep Grid)

## 基本信息

| 条目 | 内容 |
|------|------|
| 全称 | Repertory Grid Technique (Role Construct Repertory Test) |
| 缩写 | Rep Grid / RGT |
| 类型 | 个案化 (idiographic) 认知评估方法 |
| 开发者 | George A. Kelly |
| 首次发表 | 1955 |
| 理论基础 | 个人建构心理学 (Personal Construct Psychology, PCP) |
| 适用人群 | 青少年及成人 (临床、咨询、组织、教育等领域) |
| 施测时间 | 30-90 分钟 (取决于元素和建构数量) |

## 理论基础

### 个人建构理论 (PCP) 核心观点

- 人是"朴素科学家" (naive scientist),通过建构系统理解和预测世界
- **建构 (Construct)**: 双极性的区分维度 (如 "友善的 -- 冷漠的")
- **元素 (Element)**: 建构所应用的对象 (如人物、事件、情境)
- 建构是个人独特的,不同人使用不同的建构系统来理解同一现实
- 人的心理困扰源于建构系统的僵化、不足或内部矛盾

### 与传统量表的区别

| 传统量表 | 建构格栅 |
|----------|----------|
| 法则化 (nomothetic) | 个案化 (idiographic) |
| 研究者预设维度 | 参与者生成维度 |
| 标准化题项 | 每个人的格栅独特 |
| 组间比较方便 | 强调个体内部结构 |

## 格栅的三个核心组件

### 1. 元素 (Elements)

被评定的对象,通常来自同一论域 (universe of discourse):

**常见元素类型:**
- 人物 (如 "我自己", "理想自我", "我的母亲", "我最敬佩的人")
- 产品/品牌
- 工作角色
- 情境/事件
- 治疗方案

**元素来源:**
- 研究者提供 (supplied)
- 参与者自行提名 (elicited) -- 更符合 PCP 精神
- 混合使用

典型数量: 8-15 个元素

### 2. 建构 (Constructs)

双极性的区分维度,包含:
- **相似极 (Emergent Pole)**: 如 "友善的"
- **对比极 (Contrast/Implicit Pole)**: 如 "冷漠的"

**建构引出方法:**

**(a) 三元组法 (Triadic Elicitation) -- Kelly 原始方法:**
1. 从元素中选出三个
2. 问: "这三者中,哪两个在某方面相似,而与第三个不同?"
3. 用一个词/短语描述相似之处 (相似极) 和不同之处 (对比极)
4. 更换三元组重复此过程

**(b) 其他引出方法:**
- 二元组法 (Dyadic): 两两比较
- 阶梯法 (Laddering): 追问 "为什么这对你重要?" 以获取更核心的建构
- 金字塔法 (Pyramiding): 追问 "怎样的人会是...?" 以获取更具体的建构
- 自发列举
- 研究者提供

典型数量: 8-20 个建构

### 3. 评定 (Ratings)

每个元素在每个建构上的评分:

| 评定方式 | 说明 |
|----------|------|
| 二分法 (Kelly 原始) | 勾选元素属于哪一极 |
| 等级量表 | 5 点或 7 点 Likert 量表 (最常用) |
| 排序法 | 在建构上对所有元素排序 |

### 示例格栅

| 建构 (相似极) | 我自己 | 理想自我 | 母亲 | 最好的朋友 | 不喜欢的人 | 建构 (对比极) |
|---------------|--------|----------|------|------------|------------|---------------|
| 温暖的 | 5 | 7 | 6 | 7 | 2 | 冷漠的 |
| 有野心的 | 4 | 6 | 3 | 5 | 6 | 安于现状的 |
| 开放的 | 6 | 7 | 3 | 6 | 1 | 封闭的 |

(1 = 完全符合对比极, 7 = 完全符合相似极)

## 施测程序

1. **确定研究问题和论域** -- 明确格栅将探索什么领域
2. **选择/引出元素** -- 根据研究目的确定元素列表
3. **引出建构** -- 使用三元组法或其他方法引出双极建构
4. **评定** -- 参与者在每个建构上评定每个元素
5. **分析** -- 使用统计方法分析格栅数据
6. **反馈与讨论** -- 在临床/咨询中,与来访者一起探讨格栅反映的认知结构

## 分析方法

### 定量分析
- **主成分分析 (PCA)**: 提取建构空间的主要维度
- **聚类分析**: 识别相似的元素和建构群组
- **距离测量**: 元素间的欧氏距离 (如自我与理想自我的距离)
- **建构间相关**: 识别建构系统的分化与整合程度

### 关键指标
| 指标 | 含义 |
|------|------|
| 自我-理想自我距离 | 自尊/自我接纳 (距离越小越积极) |
| 建构分化 (Differentiation) | 建构系统的复杂性 |
| 建构紧密度 (Tightness) | 第一主成分解释的方差 (过高可能反映僵化) |
| 冲突指标 | 建构间的逻辑矛盾 |

### 分析软件
- **Idiogrid** (Thomas Feixas): 免费学术软件
- **GridSuite**: 在线工具
- **WebGrid** / **RepGrid IV**: 多种版本
- **OpenRepGrid** (R 包): 开源

## 心理测量学属性

由于格栅的个案化特性,传统心理测量指标的适用性受限:

| 指标 | 说明 |
|------|------|
| 重测信度 | 建构内容: 中等 (.50-.80); 结构特征: 较高 (.70-.90) |
| 评分者间信度 | 不适用 (被试自行评定) |
| 效度 | 内容效度高 (建构来自被试本人); 构念效度取决于具体应用 |
| 敏感性 | 对治疗变化敏感,可用于追踪认知结构的改变 |

### 方法论优势
- 最小化研究者偏见 (建构由参与者自己产生)
- 兼具定性与定量分析
- 可重复施测以追踪变化
- 灵活适应不同研究领域

## 中文版本状况

- 格栅技术本身具有跨文化适应性,因为建构由参与者用母语生成
- 中国心理学与管理学研究中已有使用 (如组织行为、临床心理)
- Fransella 等 (2004) 的手册有中文翻译参考
- 关键考量: 翻译需求主要在指导语和施测程序上,建构内容天然本土化
- 分析软件大多支持中文输入

## 版权与获取

- **方法本身**: 格栅技术作为研究方法不受版权限制,可自由使用
- **手册**: Fransella 等 (2004) *A Manual for Repertory Grid Technique* 可通过 Wiley 购买
- **培训**: 无需正式认证,但建议通过阅读手册和工作坊学习
- **软件**: 多数分析软件免费或开源
- **应用门槛**: 相对较低,但高质量的使用需要对 PCP 理论和格栅分析方法有深入理解
