## Overview

The SNAP-2 is a **390-item self-report inventory** that assesses personality traits on a continuum from normal/adaptive to abnormal/maladaptive functioning. It was developed through **factor analysis** of personality disorder criteria and related constructs, emphasizing the extreme ends of trait dimensions that are at the core of personality disorder.

| Property        | Value                     |
|-----------------|---------------------------|
| Total items     | 390                       |
| Trait scales    | 15                        |
| Temperament scales | 3                      |
| Diagnostic scales | 13 (10 DSM PD + 3 validity) |
| Response format | True / False              |
| Admin time      | 45–60 min                 |
| Age range       | 18+                       |
| Population      | Clinical and non-clinical |

## Scale Structure

### 3 Higher-Order Temperament Dimensions

| Dimension | Core Scale | Description |
|-----------|-----------|-------------|
| **Negative Affectivity (NA)** | Negative Temperament | Broad tendency toward negative emotional experiences |
| **Positive Affectivity (PA)** | Positive Temperament | Broad tendency toward positive emotional experiences and social engagement |
| **Disinhibition vs. Constraint (DvC)** | Disinhibition | Impulsive, undercontrolled behavior vs. planful constraint |

### 15 Primary Trait Scales (organized by domain)

#### Negative Affectivity Domain (7 scales)

| Scale | Description |
|-------|-------------|
| **Negative Temperament** | Core NA scale; pervasive negative emotionality, distress, irritability |
| **Mistrust** | Suspiciousness, doubt about others' motives |
| **Manipulativeness** | Willingness to exploit and deceive others for personal gain |
| **Aggression** | Hostile, combative, intimidating interpersonal style |
| **Self-Harm** | Self-destructive behaviors and suicidal ideation |
| **Eccentric Perceptions** | Unusual perceptual experiences, magical thinking |
| **Dependency** | Excessive reliance on others, need for reassurance |

#### Positive Affectivity Domain (4 scales)

| Scale | Description |
|-------|-------------|
| **Positive Temperament** | Core PA scale; energy, joy, sociability |
| **Exhibitionism** | Need for attention, dramatic self-presentation |
| **Entitlement** | Grandiose sense of superiority and deserved special treatment |
| **Detachment** | Social withdrawal, anhedonia *(reverse pole of PA dimension)* |

#### Disinhibition vs. Constraint Domain (4 scales)

| Scale | Description |
|-------|-------------|
| **Disinhibition** | Core DvC scale; impulsivity, risk-taking, poor self-regulation |
| **Impulsivity** | Acting without forethought, difficulty delaying gratification |
| **Propriety** | Conformity to social norms, rule-following *(reverse-scored; constraint pole)* |
| **Workaholism** | Compulsive dedication to work, perfectionism *(reverse-scored; constraint pole)* |

### Diagnostic Scales (10 DSM PD scales)

The SNAP-2 contains **10 personality disorder scales** corresponding to DSM-5 categorical PDs, computed by summing specific item subsets:

| Scale | DSM-5 PD |
|-------|----------|
| PAR   | Paranoid |
| SZD   | Schizoid |
| SZT   | Schizotypal |
| ATS   | Antisocial |
| BDL   | Borderline |
| HST   | Histrionic |
| NAR   | Narcissistic |
| AVD   | Avoidant |
| DEP   | Dependent |
| OBC   | Obsessive-Compulsive |

### Validity Scales (3 scales)

| Scale | Description |
|-------|-------------|
| **VRIN (Variable Response Inconsistency)** | Detects random responding |
| **TRIN (True Response Inconsistency)** | Detects acquiescence or nay-saying |
| **Rare Virtues / Deviance** | Detects unlikely virtue claims or rare pathological endorsements |

## Response Format

True / False (dichotomous)

---

## Scoring

- **Raw scores** converted to T-scores using community adult norms.
- **Normative sample:** Community adults from three US cities/metropolitan areas; balanced for gender and representative of broad demographic diversity (age, race/ethnicity, SES, geographic region, urban/rural).
- Profile interpretation emphasizes dimensional trait elevations and configuration across the three temperament domains.

---

## Psychometric Properties

- **Internal consistency:** Median alpha = .80–.85 across trait scales; range .75–.91 (community and clinical samples).
- **Test-retest reliability:** Median r = .80+ (1-week interval); moderate-to-good stability over longer periods, consistent with trait-level measurement.
- **Factor structure:** Three-factor temperament structure (NA, PA, DvC) robustly replicated. "Big Four" personality scales (Neuroticism, Conscientiousness, Introversion, Antagonism) derivable from SNAP-2 items.
- **Convergent validity:** Trait scales correlate substantially with corresponding NEO-PI-R domains and DAPP-BQ dimensions.
- **Discriminant validity:** PD diagnostic scales demonstrate appropriate convergent-discriminant patterns with SCID-II PD diagnoses.
- **Clinical utility:** Diagnostic scales show temporal stability and predictive validity for PD diagnosis over time.

## Chinese Version Status

- As of 2025, **no formally published Chinese adaptation** of the SNAP-2 has been identified in the English-language literature.
- The SNAP-2 has been validated in Italian and other European samples, demonstrating cross-cultural transportability of the three-factor temperament structure.
- Chinese researchers studying personality pathology dimensions have more commonly used the **DAPP-BQ** or the **PID-5** rather than the SNAP-2.
- For a personality pathology dimensional measure validated in Chinese, the **CPAI-2** (Cross-cultural Personality Assessment Inventory) or **PID-5 Chinese version** may serve as alternatives.
