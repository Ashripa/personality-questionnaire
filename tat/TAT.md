# Thematic Apperception Test (TAT)

## 基本信息

| 条目 | 内容 |
|------|------|
| 全称 | Thematic Apperception Test |
| 缩写 | TAT |
| 类型 | 投射性人格评估 (叙事/故事讲述法) |
| 开发者 | Henry A. Murray & Christiana D. Morgan |
| 首次发表 | 1935 (初步); 1943 (完整版手册) |
| 刺激材料 | 31 张图片 (30 张黑白模糊情境图 + 1 张空白卡) |
| 适用人群 | 儿童、青少年及成人 (不同图片适用不同群体) |
| 施测时间 | 约 60-120 分钟 (完整施测); 实践中常 20-40 分钟 |
| 出版商 | Harvard University Press; Pearson Clinical Assessment |

## APA 引用

### 标记系统

图片编号后的字母标识适用群体:
- **无标记**: 适用于所有被试
- **B (Boy)**: 男孩
- **G (Girl)**: 女孩
- **M (Male)**: 成年男性
- **F (Female)**: 成年女性
- **BM**: 男孩和成年男性
- **GF**: 女孩和成年女性
- **BG**: 男孩和女孩
- **MF**: 成年男性和成年女性

### 实际使用

Murray 原始设计为两次施测 (各 10 张),间隔一周。实际临床中:
- 通常选用 8-12 张最相关的图片
- 很少进行第二次施测
- 图片选择基于临床判断和转介问题

## 施测程序

### 标准指导语 (Murray 原版)

1. 告知被试这是一个想象力测验
2. 每张图片呈现后要求被试:
   - 描述画面中正在发生什么 (What is happening?)
   - 这个情境是怎么产生的 (What led up to this?)
   - 人物在想什么、感受什么 (What are the characters thinking and feeling?)
   - 结局会怎样 (What will happen next / How will it end?)
3. 鼓励被试自由发挥想象

### 施测要点

- 通常一对一施测
- 全程逐字记录或录音
- 每个故事通常 3-5 分钟
- 询问阶段: 必要时对模糊之处进行追问

## 计分系统

### Murray 原始需求-压力系统

| 维度 | 说明 |
|------|------|
| 需求 (Needs) | 主人公表现出的心理需求 (如成就、亲和、攻击、自主) |
| 压力 (Press) | 环境对主人公施加的力量 (如支配、拒绝、危险) |
| 主题 (Thema) | 需求与压力的交互模式 |

### 现代标准化计分系统

**(a) SCORS-G (Social Cognition and Object Relations Scale -- Global Rating Method)**

Westen (1991) 开发, 当前最受推荐的计分系统:

| 维度 | 评估内容 |
|------|----------|
| 他人表征的复杂性 (COM) | 对他人的理解是否复杂、多面 |
| 情感关系品质 (AFF) | 人际关系的情感基调 |
| 情绪体验与管理 (EIM) | 情绪调节能力 |
| 社会因果关系 (SC) | 对社会事件原因的理解 |
| 攻击性体验与管理 (AGG) | 攻击性的表达与控制 |
| 自尊 (SE) | 自我评价的品质 |
| 同一性与连贯性 (ICS) | 自我感的稳定性 |
| 道德标准理解 (EIR) | 道德推理的发展水平 |

每个维度 1-7 分评定。

**(b) 其他计分系统:**
- McClelland 成就动机计分 (n Ach)
- 亲密动机计分 (McAdams)
- 权力动机计分 (Winter)
- Defense Mechanism Manual (DMM)

## 心理测量学属性

### 传统心理测量指标

| 指标 | 数值/状况 |
|------|-----------|
| 评分者间信度 (SCORS-G) | ICC = .70-.90 (经培训的评分者) |
| 评分者间信度 (非正式解读) | 低且不一致 |
| 内部一致性 | 一般较低 (.30-.50),但投射测验的预期 |
| 重测信度 | 争议较大; 动机计分: .50-.70 |
| 效度 (SCORS-G) | 与人格障碍诊断、治疗结果显著相关 |
| 效度 (成就动机) | 可预测实际成就行为 (McClelland 研究) |
| 增量效度 | 使用 SCORS-G 时对自我报告有增量效度 |

### 争议

- 缺乏统一的标准化计分方法是最大批评
- 非正式/直觉式解读的信度和效度不佳
- 使用标准化计分系统 (如 SCORS-G) 时心理测量属性显著改善
- 图片年代久远,部分场景与当代生活脱节

## 中文版本状况

- **TAT-R,C (中国修订版)**: 中国科学院心理研究所于 1993 年发表了"主题统觉测验中国修订版"的编制与常模研究 (《心理学报》)
- 修订版对部分图片进行了文化适应性调整
- 中国临床实践中 TAT 有一定使用,但远不如 MMPI 等客观测验普及
- 台湾地区也有使用 TAT 的临床与研究传统
- 中文名称: 主题统觉测验 / 主題統覺測驗

## 版权与获取

- **图片材料**: 通过 Pearson Clinical Assessment 或 Harvard University Press 购买
- **Pearson 产品页**: TAT 完整套件可在 pearsonassessments.com 订购
- **价格**: 完整图片套件约 $80-120 USD
- **资质要求**: C 级资质 (需具备临床心理学或相关博士学位)
- **计分手册**: SCORS-G 培训手册可通过学术渠道获取
- **培训**: SCORS-G 编码需要培训,通常通过研究生课程或工作坊进行
- **替代方案**: 部分图片描述可在教科书中找到,但原始图片受版权保护
